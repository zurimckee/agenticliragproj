# Task: Add an "invert" filter

**Project:** thatdamndog (Streamlit image filter app)
**Files involved:** new file (e.g. `invert.py`), `app.py`
**Language:** Python
**Difficulty:** Easy
**Retrieval style:** exact-term match (mirrors the existing filter pattern directly)

## Description

Add a new filter called "invert" that inverts each pixel's color (each of
R, G, and B becomes `255 - value`). Follow the same structure already used
by the existing filters (see `grayscale.py` or `dogjail.py`): a function
that takes the same pixel-list format and returns a new pixel list in that
same format, with a `if __name__ == '__main__':` block that mirrors the
existing ones for standalone testing.

Register the new filter in `app.py`'s filter dictionary so it shows up
alongside the existing options.

## Constraints
- Do not modify `image_converter.py` (it's marked "DO NOT EDIT THIS FILE").
- Follow the existing per-pixel loop style already used in the other filter
  files rather than introducing a different approach (e.g. numpy vectorized
  operations) — consistency with the rest of the codebase matters here.
